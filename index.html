The problem

A grower with a diseased pomegranate needs a clear answer from a single phone photo. Our first model could give one, but at about 500 MB it was far too heavy to ship inside an app people would actually open.

My solution

I led a team of six from model to live product. We trained on 5,099 images covering 4 diseases and healthy fruit, then rebuilt the model with MobileNetV2 transfer learning, which made it about 50× smaller. Around it we built a Streamlit app with login, scan history, weather, crop advice and government-scheme pages in more than one language, backed by MongoDB Atlas.

The impact

93.92% validation accuracy and a 0.93 macro F1-score from a 9.59 MB model. The app is live, and the work became a first-author research paper accepted at IC2NC 2026.

Tech stack

  • Python
  • TensorFlow / Keras
  • MobileNetV2
  • Streamlit
  • MongoDB Atlas
Live demo View code Research paper

Limitations & next steps: Works for pomegranate only — 4 diseases plus healthy fruit — and the 93.92% figure is validation accuracy.

SkillMap AI

Solo project · AI resume & ATS analyzer · 2026

Live

2
AI models · main + backup
Solo
Built end to end

The problem

When you apply for a job, it is hard to tell how well your resume matches that specific job description, or which skills it is missing.

My solution

Upload a resume and paste a job description to get an ATS match score, the skills you have and the ones you're missing. Gemini returns its answer in a fixed JSON format, and a backup model takes over when the main one is busy or out of quota. The app is React and TypeScript on the front, Node.js and Express behind it, with PostgreSQL through Prisma.

The impact

Live on Render and Neon as a complete product: sign-up with secure sessions, password reset by email, a score-history dashboard, and free courses suggested for each missing skill.

Tech stack

  • React
  • TypeScript
  • Node.js
  • Express
  • PostgreSQL (Prisma)
  • Gemini API
  • Render + Neon
Live demo View code

Limitations & next steps: The match score is an AI estimate from Gemini, not the output of any employer's own ATS.

The problem

A blood report is dense with medical terms and numbers. That is hard for most people to follow, and harder still for someone more comfortable in Marathi or Hindi than in English.

My solution

The app reads a blood-report PDF and explains each result in simple Marathi, Hindi or English. Gemini pulls out the values, explains the medical terms and flags results that need a doctor urgently, and the device's built-in voice reads the explanation aloud. It runs on React and TypeScript with Vercel serverless functions, MongoDB Atlas and Clerk sign-in.

The impact

Live on Vercel. Charts track results across reports, sign-in keeps them private, and PDFs are deleted right after processing. First built at the OpenAI × Outskill AI Builders Hackathon.

Tech stack

  • React
  • TypeScript
  • Vercel Serverless
  • Gemini API
  • MongoDB Atlas
  • Clerk
Live demo View code

Limitations & next steps: It explains a report in plain language; it does not diagnose, and it is not a replacement for a doctor.
