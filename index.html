P/01 · 2025–26 Featured

KrushiAI

Team Lead · 6 members · AI crop-disease detection

An app that spots pomegranate diseases from a single photo. I led a team of six from model to live product: we trained on 5,099 images covering 4 diseases and healthy fruit, then rebuilt our first ~500 MB model with MobileNetV2 transfer learning to make it about 50× smaller. The app adds login, scan history, weather, crop advice and government-scheme pages in more than one language.

P/02 · 2026

SkillMap AI

Solo project · AI resume & ATS analyzer

Upload a resume and paste a job description to get an ATS match score, the skills you have and the ones you're missing. Gemini returns a fixed JSON format, with a backup model when the main one is busy or out of quota. Includes sign-up with secure sessions, password reset by email, a score-history dashboard, and free courses for each missing skill.

React TypeScript Node.js Express PostgreSQL (Prisma) Gemini API Render + Neon
Live demo Code
P/03 · 2026

Paper Trail

Solo project · Multilingual medical report explainer

Reads a blood-report PDF and explains each result in simple Marathi, Hindi or English. Gemini pulls out the values, explains medical terms and flags results that need a doctor urgently, and the device's built-in voice reads it aloud. Charts track results across reports, sign-in keeps them private, and PDFs are deleted right after processing. First built at the OpenAI × Outskill AI Builders Hackathon.

React TypeScript Vercel Serverless Gemini API MongoDB Atlas Clerk
Live demo Code

A platform that helps students in Maharashtra find government jobs and prepare for competitive exams. Built end-to-end — React frontend, FastAPI backend and MongoDB — with AI guidance from the Claude API and Marathi support so students can use it in their own language. SafarSathi & TyreSense

Edge AI system designs · Tata Technologies InnoVent-27

SafarSathi is an offline car-diagnosis assistant on Raspberry Pi / Jetson Nano that reads OBD-II data and explains faults by voice in Hindi and Marathi, with no internet needed. TyreSense is a tyre-health monitor that uses an ESP32 and MEMS motion sensors to check tyres on the device itself. Full system designs and pitch decks prepared for the hackathon.
